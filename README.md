# ATLA
Daily Digest with Engram Chat

## Engram Daily downloads

The [release downloads](https://github.com/Tech953/ATLA/releases/tag/engram-daily-0.2.1) include the Windows 0.2.1 recovery installer, the older Windows 0.2.0 installer, the Android 0.1.0 test APK, and the two original source archives. Verify a download against [SHA256SUMS](downloads/SHA256SUMS).

| Platform | Source | Setup and verification |
| --- | --- | --- |
| Windows | [Windows project](EngramDailyWindows) | [0.2.1 startup guide](docs/Engram-Daily-0.2.1-Startup-Guide.md) and [functionality audit](docs/Engram-Functionality-Audit.md) |
| Android | [Android project](EngramDaily) | [Build and device instructions](EngramDaily/README.md) |

The [Jade calendar guide](docs/Jade-ChatGPT-Calendar.md) covers the ChatGPT companion. The project folders include the original Jade and third-party notices. The Windows recovery installer is unsigned, and startup on the affected Windows laptop still needs device verification.
